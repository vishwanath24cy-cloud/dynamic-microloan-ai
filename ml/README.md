# Machine Learning Module

This directory contains machine learning pipelines, feature engineering scripts, and model inference modules for:
- Cash-flow prediction (forecasting borrower revenue and expense cycles)
- Dynamic repayment optimization (adjusting installment amounts based on forecasted surplus)
- Risk scoring / early warning indicators for repayment delays

## Structure
- `predictor_stub.py`: Baseline stub for cash-flow projection and installment adjustment logic.
- Place trained model artifacts (e.g. `.pkl`, `.onnx`, or weights) and notebooks here.
